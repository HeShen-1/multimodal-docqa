## 快速开始

### 环境要求

- Python 3.11+
- Ollama 0.5.0+
- PostgreSQL 15+
- Redis 7.0+
- Docker 24.0+（可选）

### 安装步骤

**1. 克隆项目**
```bash
git clone https://github.com/yourname/multimodal-docqa.git
cd multimodal-docqa/backend
```

**2. 创建虚拟环境**
```bash
# 使用Anaconda（推荐）
conda create -n multimodal-docqa python=3.11 -y
conda activate multimodal-docqa

# 或使用venv
python3.11 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

**3. 安装依赖**
```bash
pip install -r requirements.txt
```

**4. 配置环境变量**
```bash
cp .env.example .env
# 编辑.env文件，配置数据库连接等信息
```

**5. 启动基础服务**
```bash
# 使用Docker Compose启动PostgreSQL、Redis、Milvus
docker-compose up -d
```

**6. 初始化数据库**
```bash
python scripts/init_db.py
```

**7. 启动Ollama并拉取模型**
```bash
# 启动Ollama服务
ollama serve

# 拉取模型
ollama pull qwen3-vl:2b-thinking
ollama pull qwen3-embedding:0.6b-fp16
```

**8. 启动后端服务**
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**9. 访问API文档**
```
http://localhost:8000/docs
```

### 2. Embedding服务模块

**功能**: 调用Ollama的embedding模型，将文本和图像转换为向量。

**核心类**: `EmbeddingService`

**主要方法**:

```python
class EmbeddingService:
    """向量化服务"""
    
    def __init__(self, settings: Settings):
        self.ollama_base_url = settings.ollama_base_url
        self.embedding_model = settings.ollama_embedding_model
        self.chroma_client = chromadb.PersistentClient(
            path=settings.chroma_persist_dir
        )
        self.text_collection = self.chroma_client.get_or_create_collection(
            name="text_chunks",
            metadata={"hnsw:space": "cosine"}
        )
    
    async def encode_text(self, texts: List[str]) -> List[List[float]]:
        """
        文本向量化
        
        Args:
            texts: 文本列表
            
        Returns:
            向量列表
        """
        response = requests.post(
            f"{self.ollama_base_url}/api/embed",
            json={
                "model": self.embedding_model,
                "input": texts
            }
        )
        return response.json()["embeddings"]
    
    async def add_text_chunks(self, chunks: List[Dict]):
        """
        添加文本块到向量数据库
        
        Args:
            chunks: 文本块列表，每个包含content和metadata
        """
        texts = [chunk['content'] for chunk in chunks]
        embeddings = await self.encode_text(texts)
        metadatas = [chunk['metadata'] for chunk in chunks]
        ids = [chunk['id'] for chunk in chunks]
        
        self.text_collection.add(
            documents=texts,
            embeddings=embeddings,
            metadatas=metadatas,
            ids=ids
        )
```

**开发要点**:
- 使用requests库调用Ollama API
- 批量处理文本，提升效率（建议每批8-16条）
- ChromaDB使用cosine距离度量
- Milvus需要先创建Collection Schema
- 实现重试机制，处理网络异常
- 添加缓存，避免重复向量化

### 3. 检索服务模块

**功能**: 实现混合检索（向量+BM25+图像），使用RRF融合算法。

**核心类**: `RetrievalService`

**主要方法**:

```python
class RetrievalService:
    """混合检索服务"""
    
    def __init__(self, embedding_service: EmbeddingService):
        self.embedding_service = embedding_service
        self.bm25_index = None  # BM25索引
    
    async def hybrid_search(
        self, 
        query: str, 
        top_k: int = 5,
        document_ids: List[str] = None
    ) -> List[Dict[str, Any]]:
        """
        混合检索
        
        Args:
            query: 查询文本
            top_k: 返回结果数量
            document_ids: 指定文档ID列表
            
        Returns:
            融合后的检索结果
        """
        # 并行执行多路检索
        vector_results, bm25_results = await asyncio.gather(
            self._vector_search(query, top_k * 2, document_ids),
            self._bm25_search(query, top_k * 2, document_ids)
        )
        
        # RRF融合
        fused_results = self._rrf_fusion(
            [vector_results, bm25_results],
            top_k
        )
        
        return fused_results
    
    async def _vector_search(
        self, 
        query: str, 
        top_k: int,
        document_ids: List[str] = None
    ) -> List[Dict]:
        """向量检索"""
        # 查询向量化
        query_embedding = await self.embedding_service.encode_text([query])
        
        # ChromaDB检索
        where_filter = None
        if document_ids:
            where_filter = {"document_id": {"$in": document_ids}}
        
        results = self.embedding_service.text_collection.query(
            query_embeddings=query_embedding,
            n_results=top_k,
            where=where_filter
        )
        
        return self._format_results(results)
    
    def _rrf_fusion(
        self, 
        results_list: List[List[Dict]], 
        top_k: int,
        k: int = 60
    ) -> List[Dict]:
        """
        RRF融合算法
        
        Args:
            results_list: 多路检索结果列表
            top_k: 返回数量
            k: RRF常数（默认60）
            
        Returns:
            融合后的结果
        """
        # 收集所有文档
        doc_scores = {}
        
        for results in results_list:
            for rank, doc in enumerate(results, start=1):
                doc_id = doc['id']
                score = 1.0 / (k + rank)
                
                if doc_id in doc_scores:
                    doc_scores[doc_id]['score'] += score
                else:
                    doc_scores[doc_id] = {
                        'doc': doc,
                        'score': score
                    }
        
        # 按分数排序
        sorted_docs = sorted(
            doc_scores.values(),
            key=lambda x: x['score'],
            reverse=True
        )
        
        return [item['doc'] for item in sorted_docs[:top_k]]
```

**开发要点**:
- 使用asyncio.gather并行执行多路检索
- BM25索引使用rank-bm25库，需要预先构建
- RRF融合时k值通常设为60
- 支持元数据过滤（如指定文档ID）
- 实现结果缓存，提升性能
- 记录检索统计信息（各路结果数量、耗时等）

**BM25索引构建**:
```python
from rank_bm25 import BM25Okapi
import jieba

def build_bm25_index(documents: List[Dict]):
    """构建BM25索引"""
    # 分词
    tokenized_docs = [
        list(jieba.cut(doc['content'])) 
        for doc in documents
    ]
    
    # 创建BM25索引
    bm25 = BM25Okapi(tokenized_docs)
    
    return bm25, documents
```

### 4. LLM服务模块

**功能**: 调用Ollama的Qwen3-VL模型，生成带有Thinking Chain的回答。

**核心类**: `LLMService`

**主要方法**:

```python
class LLMService:
    """LLM调用服务"""
    
    def __init__(self, settings: Settings):
        self.ollama_base_url = settings.ollama_base_url
        self.model_name = settings.ollama_llm_model
    
    async def generate_answer(
        self,
        query: str,
        context: List[Dict],
        stream: bool = False,
        temperature: float = 0.7
    ) -> Union[Dict, AsyncGenerator]:
        """
        生成答案
        
        Args:
            query: 用户问题
            context: 检索到的上下文
            stream: 是否流式输出
            temperature: 生成温度
            
        Returns:
            答案字典或流式生成器
        """
        # 构建prompt
        prompt = self._build_prompt(query, context)
        
        # 准备请求
        payload = {
            "model": self.model_name,
            "prompt": prompt,
            "stream": stream,
            "options": {
                "temperature": temperature,
                "top_p": 0.9,
                "num_predict": 1024
            }
        }
        
        if stream:
            return self._generate_stream(payload)
        else:
            return await self._generate_once(payload)
    
    def _build_prompt(self, query: str, context: List[Dict]) -> str:
        """构建提示词"""
        from app.prompts import THINKING_PROMPT
        
        # 格式化上下文
        context_text = "\n\n".join([
            f"[来源: {ctx['fileName']}, 第{ctx['page']}页]\n{ctx['content']}"
            for ctx in context
        ])
        
        # 填充模板
        return THINKING_PROMPT.format(
            context=context_text,
            question=query
        )
    
    def parse_thinking_chain(self, response: str) -> Dict:
        """解析Thinking Chain"""
        import re
        
        # 提取thinking部分
        thinking_match = re.search(
            r'<thinking>(.*?)</thinking>', 
            response, 
            re.DOTALL
        )
        
        # 提取answer部分
        answer_match = re.search(
            r'<answer>(.*?)</answer>', 
            response, 
            re.DOTALL
        )
        
        # 解析thinking步骤
        thinking_steps = []
        if thinking_match:
            thinking_text = thinking_match.group(1)
            steps = re.findall(
                r'\d+\.\s*([^:：]+)[：:]\s*([^\n]+)', 
                thinking_text
            )
            thinking_steps = [
                {"step": step[0].strip(), "content": step[1].strip()}
                for step in steps
            ]
        
        answer = answer_match.group(1).strip() if answer_match else response
        
        return {
            "thinking": thinking_steps,
            "answer": answer
        }
```

**开发要点**:
- 使用requests库调用Ollama API
- 流式输出使用aiohttp，逐token返回
- Prompt构建时注意上下文长度限制
- 解析Thinking Chain时使用正则表达式
- 实现超时和重试机制
- 记录生成耗时和token数量

**流式输出实现**:
```python
import aiohttp

async def _generate_stream(self, payload: Dict) -> AsyncGenerator:
    """流式生成"""
    async with aiohttp.ClientSession() as session:
        async with session.post(
            f"{self.ollama_base_url}/api/generate",
            json=payload
        ) as response:
            async for line in response.content:
                if line:
                    data = json.loads(line)
                    if "response" in data:
                        yield data["response"]
```
